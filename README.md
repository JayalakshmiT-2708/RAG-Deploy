# 📚 RAG-Based Smart Document Analyzer (Flask + LangChain)

## 🚀 Overview
This project is a **Retrieval-Augmented Generation (RAG) system** built using Flask and LangChain.

It allows users to upload PDF documents and ask intelligent questions based on their content.  
The system retrieves relevant document chunks using vector search and generates accurate answers using a Large Language Model (Mistral AI).

---

## ✨ Features
- 📄 Upload and process PDF documents  
- 🔍 Intelligent text chunking and embedding  
- 🧠 Semantic search using ChromaDB vector database  
- 💬 Ask questions from uploaded documents  
- 🤖 AI-powered answers using Mistral LLM  
- 🌐 Simple Flask web interface  

---

## 🛠️ Tech Stack
- Python  
- Flask  
- LangChain  
- LangChain Mistralai  
- Mistral AI  
- ChromaDB (Vector Database)  
- Sentence Transformers (Embeddings)  
- PyPDF  
- HTML (Frontend Templates)
